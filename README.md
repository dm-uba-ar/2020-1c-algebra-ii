### Correlatividades

De acuerdo con el régimen de
correlatividades vigente, para poder cursar esta materia es necesario
tener aprobados los trabajos prácticos de Álgebra Lineal y el final de
Álgebra I.

### Régimen de aprobación

Se deben aprobar dos exámenes parciales. Habrá dos fechas de recuperación
al finalizar el cuatrimestre, una para cada examen. Para poder ser incluído
en las actas de trabajos prácticos, es necesario haberse inscripto en la
materia mediante el [sistema de inscripciones de la facultad](http://inscripciones.exactas.uba.ar/exactas/), y haber
completado la encuesta final de evaluación docente.
